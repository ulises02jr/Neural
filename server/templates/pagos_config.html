No es necesaria para recibir pagos. Solo si más adelante querés consultar la API de Lemon Squeezy.

Cómo crear el webhook en Lemon Squeezy

  1. En Lemon Squeezy: Settings → Webhooks → +.
  2. Callback URL: https://neuralworship.com/api/webhooks/lemonsqueezy
  3. Signing secret: inventá un texto largo (letras y números) y pegalo también aquí arriba. Deben ser idénticos.
  4. Eventos: marcá los que empiezan con subscription_ (created, updated, cancelled, expired, payment_success).
  5. Guardá el webhook, pegá el mismo secreto aquí y dale Guardar.
  6. Probá una suscripción en modo test de Lemon Squeezy (sin tarjeta real).
